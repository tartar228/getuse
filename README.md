# GetUse

Telegram Mini App: игра-убивалка времени, в которой выбиваешь красивые юзернеймы для разных соцсетей.
Игра личная, не для публикации. Юзы генерируются случайно и с настоящими аккаунтами не связаны, а в словаре есть
имена и ники известных людей, чтобы они ценились как в жизни. Валюта только внутриигровая (₽ и @).

React + Vite, без сервера. Прогресс хранится в Telegram CloudStorage, запасной вариант — localStorage.

## Что есть в игре

- крутка на 1, 2, 3 или 5 раз сразу: самый ценный юз показывается крупно, остальные выглядывают списком
  (забрать по одному или «Продать остальные» одной кнопкой)
- слоты коллекции (12 + за уровни + покупка пар мест за ₽), уровень и опыт с ништяками, талисманы:
  по одному юзу на редкость, чем выше редкость, тем больше удачи (крутка берёт лучший из нескольких попыток)
- пробив: оценка любого введённого юза по тем же правилам, плюс цена на других платформах
- биржа с NPC, свои лоты, офферы, события, новости, цены
- на телефонах открывается на весь экран (Bot API 8.0+), отступы берутся из `--tg-*-safe-area-inset-*`

## Запуск

```bash
npm install
npm run dev        # локально, в браузере (вне Telegram игра работает на localStorage)
npm run build      # продакшен-сборка в dist/
npm run stats      # симуляция дропа: шансы тиров, экономика (пишет src/game/dropStats.json)
```

`npm run build` сам пересчитывает шансы тиров перед сборкой.

## Настройка бота

1. В @BotFather создай Mini App (`/newapp`), укажи адрес, где лежит сборка (нужен HTTPS).
2. Скопируй `.env.example` в `.env` и пропиши юзернейм бота и короткое имя приложения — они нужны для
   ссылки в «Поделиться дропом» (`t.me/<бот>/<приложение>`).
3. Токен бота в проект класть не нужно: клиентскому приложению он не нужен.

## Деплой на GitHub Pages

В `.github/workflows/deploy.yml` уже есть workflow. После создания репозитория: Settings → Pages →
Source: GitHub Actions. Переменные `VITE_BOT_USERNAME` и `VITE_APP_SHORT_NAME` задаются в
Settings → Secrets and variables → Actions → Variables.

## Структура

- `src/game/` — чистая игровая логика без React: генератор юзов, формула ценности, словарь,
  экономика, таймер круток, уровни и слоты (`levels.js`), талисманы и удача (`talismans.js`),
  пробив (`lookup.js`), задания, симуляция биржи
- `src/theme.css` — токены дизайна (цвета, радиусы, шрифты), `src/styles.css` — компоненты и экраны
- `src/state/` — состояние игры (редьюсер) и сохранение
- `src/screens/`, `src/components/` — интерфейс
- `scripts/simulate.mjs` — симуляция для настройки баланса

## Где крутить баланс

- `src/game/economy.js` — стартовые ₽, цена крутки, процент «продать сразу», сумма за разбор
- `src/game/generator.js` — шансы пулов (мусор / паттерны / слова) и корзин словаря; `KEEP` — отбраковка высоких редкостей (чем меньше число, тем реже тир)
- `src/game/value.js` — формула цены, границы тиров, бонусы; кривая цены (`PRICE_KNEE`, `PRICE_POW`: выше порога цена растёт степенью, поэтому мифики стоят сотни тысяч и миллионы)
- `src/game/market.js` — комиссия, скорость продаж, события, тренды
- `src/game/spins.js` — таймер, запас, рост цены покупных круток
- `src/game/levels.js` — опыт, награды и ништяки уровней, цена слотов; `talismans.js` — бонусы удачи по редкостям
- `src/game/words.js`, `words-extra.js` — словарь: основной (из него выпадают слова) и расширенный (только для оценки)
- `src/game/tasks.js`, `daily.js` — задания, достижения, награды

После правок запускай `npm run stats` и смотри таблицу шансов и окупаемость круток.
